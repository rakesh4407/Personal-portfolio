## 🚀 Quick Start

```bash
git clone https://github.com/rakesh4407/Personal-portfolio.git
cd Personal-portfolio
npm install
npm run dev          # → http://localhost:5173
```

```bash
npm run build        # Production build
npm run preview      # Preview build
```

## 📁 Structure

```
src/
├── components/
│   ├── ui/                  # GlassCard · SectionHeading · SocialIcons
│   ├── Navbar.tsx           # Sticky nav + mobile menu
│   ├── Hero.tsx             # Hero with photo + CTAs
│   ├── About.tsx            # Bio + bento grid
│   ├── Skills.tsx           # 6 skill categories
│   ├── Experience.tsx       # Work timeline
│   ├── Projects.tsx         # 4 project cards (expandable)
│   ├── Education.tsx        # Academics + CGPA bar
│   ├── Achievements.tsx     # Awards & certifications
│   ├── Learning.tsx         # Current interests
│   ├── Contact.tsx          # Form (Formspree-ready)
│   ├── Footer.tsx
│   └── BackToTop.tsx
├── data/
│   └── portfolioData.ts     # ← All content in one file
├── hooks/                   # useActiveSection · useScrollReveal
├── App.tsx · main.tsx · index.css
```
