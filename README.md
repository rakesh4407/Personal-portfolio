## 🚀 Quick Start

```bash
# Clone
git clone https://github.com/rakesh4407/Personal-portfolio.git
cd Personal-portfolio

# Install
npm install

# Develop
npm run dev          # → http://localhost:5173

# Build
npm run build        # Production build → /dist
npm run preview      # Preview production build
```

## ✏️ Customization

All portfolio content is in **one file**: [`src/data/portfolioData.ts`](src/data/portfolioData.ts)

Update your personal info, skills, projects, experience — everything in one place.

### Enable Direct Email Delivery

1. Sign up free at [formspree.io](https://formspree.io)
2. Create a form → copy the endpoint URL
3. Set `formspreeEndpoint` in `portfolioData.ts`
4. Push to GitHub → auto-deploys
